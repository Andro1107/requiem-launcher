# Requiem Launcher

Download **RequiemLauncher.exe** from the Releases page and run it.

Windows will warn about an unsigned program. Click **More info**, then **Run anyway**.
It is unsigned because code signing certificates cost money, not because anything is wrong.

The first time it runs it will ask for an **access key**. Paste the one you were given.
It only asks once, and the key is stored on your computer only.

Then pick the top build and press Play. It downloads the game, checks it, and starts it.
Everything it downloads lives in a folder next to your other application data - the
launcher shows you the exact path under **Details**.

Found a bug? Tell me the **version number** shown in the launcher. Without that I cannot
tell which build you were playing.
